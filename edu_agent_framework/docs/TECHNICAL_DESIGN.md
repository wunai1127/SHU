# 教育智能体速成框架 - 技术设计文档

## 1. 项目概述

### 1.1 背景与痛点

在高校教育领域，AI助理产品面临核心瓶颈：**通用性有余而个性化不足**。

**教师核心痛点**：
1. AI生成内容缺乏教师**个人独特的教学风格**
2. 无法体现教师的**逻辑脉络**和思维方式
3. 缺少教师积累的**私域知识**（案例、例题、FAQ等）
4. 使用门槛过高，需要大量prompt engineering

### 1.2 解决方案

**教育智能体速成框架**：让高校教师通过简单配置，快速生成具有个人风格的AI教学助手。

```
教师配置 (YAML/JSON) → 框架处理 → 个性化智能体 → 学生使用
```

## 2. 教师个性化输入清单

### 2.1 输入分类

为实现个性化，教师需要提供以下四类输入：

| 类别 | 必要性 | 说明 |
|------|--------|------|
| 基本信息 | 必填 | 姓名、课程名 |
| 教学风格 | 推荐 | 教学方法、互动模式 |
| 知识体系 | 推荐 | 核心概念、学习目标 |
| 私域知识 | 强烈推荐 | FAQ、案例、类比、易错点 |

### 2.2 详细输入项

#### A. 基本信息
```yaml
name: "张三"          # 教师姓名
title: "副教授"       # 职称
institution: "XX大学" # 院校
department: "计算机系" # 院系
```

#### B. 教学风格
```yaml
primary_style: "讲授式"      # 主要教学方法
  # 可选: 苏格拉底式/讲授式/案例式/问题导向式/讨论式/翻转课堂式/支架式/故事式

interaction_mode: "鼓励支持型" # 互动模式
  # 可选: 耐心细致型/挑战激励型/鼓励支持型/严谨学术型/幽默风趣型
```

#### C. 知识体系
```yaml
domains:
  - name: "数据结构"
    level: "本科"
    core_concepts: ["链表", "栈", "队列", "树", "图"]
    prerequisite: ["C语言程序设计"]
    learning_objectives:
      - "掌握基本数据结构的原理"
      - "能够分析算法时间复杂度"
```

#### D. 教学逻辑
```yaml
teaching_logic:
  explanation_order: "概念->原理->例子->应用" # 讲解顺序
  depth_preference: "先广后深"                # 深度策略
  use_analogy: true                          # 是否用类比
  signature_phrases:                         # 特色表达
    - "这个问题很好..."
    - "换个角度想..."
```

#### E. 私域知识（最重要的个性化来源）
```yaml
private_knowledge:
  # FAQ - 学生常问的问题
  faq:
    - question: "递归和迭代有什么区别？"
      answer: "递归是函数调用自己，迭代是循环..."

  # 常见错误
  common_mistakes:
    - mistake: "混淆栈和堆"
      correction: "栈是后进先出，堆是..."

  # 类比库
  analogies:
    - concept: "递归"
      analogy: "就像俄罗斯套娃，打开一个还有一个..."

  # 教学文档
  lecture_notes:
    - "/path/to/ppt1.pptx"
    - "/path/to/lecture.pdf"
```

### 2.3 输入方式

| 方式 | 适用场景 | 门槛 |
|------|----------|------|
| 极简模式 | 快速体验 | 最低：只需姓名和课程名 |
| 模板模式 | 常规使用 | 低：选择预置模板 |
| 配置文件 | 深度定制 | 中：填写YAML文件 |
| GUI界面 | 批量管理 | 低：可视化配置（规划中） |

### 3.2 核心技术

#### A. 多层Prompt组装技术

将教师画像转换为系统提示词，采用分层组装策略：

```
System Prompt =
    角色定位层（who）
  + 教学风格层（how）
  + 知识约束层（what）
  + 教学逻辑层（logic）
  + 行为规则层（behavior）
  + 约束条件层（constraints）
```

**示例生成的Prompt**：
```
# 角色定位
你是张老师的AI教学助手，完全模拟张老师的教学风格...

# 教学风格
采用苏格拉底式教学法：
- 不直接给出答案，通过连续提问引导学生发现答案
- 每次回复至少包含一个启发性问题...

# 知识领域
## 数据结构（本科）
核心概念：链表、栈、队列、树、图...

# 教学逻辑
按照「概念->原理->例子->应用」的顺序组织内容
善于使用类比帮助理解...
```

#### B. Few-shot示例注入

将教师的私域知识转换为示例，注入到对话中：

```python
# 从FAQ生成示例
学生问：递归和迭代有什么区别？
张老师答：[教师的标准回答]

# 从类比库生成示例
讲解递归时，可以说：就像俄罗斯套娃...
```

#### C. RAG私域知识检索

对教师上传的文档建立向量索引，对话时检索相关内容：

```
用户提问 → 向量化 → 相似度检索 → 获取相关文档片段 → 增强回答
```

技术栈：
- 嵌入模型：OpenAI text-embedding-3 / 本地模型
- 向量库：FAISS
- 文档处理：PyPDF2, python-pptx, python-docx

#### D. 学习状态追踪

跟踪学生学习进度，实现因材施教：

```python
class LearningState:
    topics_covered: List[str]     # 已学主题
    questions_asked: int          # 提问次数
    misconceptions: List[str]     # 误解记录
    understanding_level: Dict     # 各主题理解程度
```

### 3.3 技术选型

| 组件 | 技术方案 | 说明 |
|------|----------|------|
| 语言 | Python 3.10+ | 生态丰富，易于集成 |
| LLM | OpenAI / DeepSeek / 本地模型 | 支持多种后端 |
| 向量库 | FAISS | 高效相似度搜索 |
| 嵌入 | text-embedding-3 / SentenceTransformers | 支持云端和本地 |
| 文档处理 | PyPDF2, python-pptx | 支持主流格式 |
| 配置格式 | YAML/JSON | 易读易写 |

### 3.4 扩展能力

框架设计支持以下扩展：

1. **新增LLM后端**：继承`BaseEduAgent`实现新的Agent类
2. **自定义教学风格**：扩展`TeachingStyle`枚举
3. **接入知识图谱**：结合现有GraphRAG能力
4. **多模态支持**：扩展文档处理器支持图片、视频

## 4. 使用流程

### 4.1 教师端流程

```
1. 选择创建方式（快速/模板/配置文件）
         ↓
2. 填写/上传配置
         ↓
3. 上传教学文档（可选）
         ↓
4. 预览生成效果
         ↓
5. 发布智能体
         ↓
6. 获取访问链接
```

### 4.2 学生端流程

```
1. 通过链接访问智能体
         ↓
2. 与AI助教对话学习
         ↓
3. 查看学习记录和进度
```

## 6. 快速开始

### 6.1 安装

```bash
pip install openai PyYAML
# 可选：pip install faiss-cpu sentence-transformers PyPDF2 python-pptx
```

### 6.2 最简示例

```python
from edu_agent_framework import EduAgentFactory

# 创建工厂
factory = EduAgentFactory()

# 一行代码创建智能体
agent = factory.create_quick("王老师", "高等数学")

# 开始对话
response = agent.chat("什么是导数？")
print(response)
```

### 6.3 使用配置文件

```python
from edu_agent_framework import EduAgentFactory

factory = EduAgentFactory()
agent = factory.create_from_config("teacher_config.yaml")
```
